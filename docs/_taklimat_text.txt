Criteria
Capstone Project consist of the following criteria:
Practical
: Software development – web based + mobile apps (with database backend)
Problem-solving oriented
: based on solving a real-life problem or addressing a specific need.
Interdisciplinary
: Combines knowledge from different subjects or courses.
Cumulative
: Draws on everything learned in your course or program.
