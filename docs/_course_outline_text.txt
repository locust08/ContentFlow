Course Learning Outcomes
At the end of the course, students should be able to: 
Design a solution to the problem in managing digital content. ( C6  )1.
 Construct an information system prototype for digital content management. ( P3  )2.
 Present the final version of the prototype. ( A2  )3.
 Compose a written report on the design and construction of the prototype. ( P7  )4.
Course Description
This course implements Capstone Design, which involves the application of knowledge and skills acquired throughout the
programme's curriculum, comprising the following major components: web programming, mobile app development, and
database design. Students are expected to develop and build a prototype of an information system for managing digital
content in an organization that fulfils each component. Additionally, a data analysis tool will be used to query and analyse
data from the completed prototype. This course also promotes the adoption of elements such as IoT, virtual reality, and
augmented reality into the development of information systems.
